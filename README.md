# 五线谱识谱训练器

🚀 **在线体验：** [https://smallteddy.github.io/pronunciation-training/](https://smallteddy.github.io/pronunciation-training/)

一个基于 Web 的五线谱识谱练习工具。无需登录，数据存储在本地浏览器，系统会根据用户常错的音自动加强练习。支持高音谱表、低音谱表及大谱表模式，移动端可在一屏内完整显示，无需滚动。

---

## 核心功能

### 🎵 24 音组练习模式（3 行五线谱）

- 一次显示 **3 行五线谱**，每行 **2 个小节**，每小节 **4 个音符**，共 **24 个单音**
- 依次识别，答对自动推进到下一个音
- 一组 24 个音结束后，**自动进入下一组**，无需手动操作
- 按 **音名字母** 匹配（C / D / E / F / G / A / B），忽略八度差异

### 🎹 7 键音名键盘（底部固定）

- 底部提供 **C D E F G A B** 七个音名按钮，固定在页面底部、无需滚动即可触达
- 电脑键盘映射：`D F G H J K L` 对应 `C D E F G A B`
- 支持鼠标点击与触摸操作，移动端体验友好

### 🎨 实时视觉反馈

- 当前待识别音符：**橙色** + 顶部 ▲ 标记
- 识别正确：音符变为 **绿色**，对应按钮绿色高亮
- 识别错误：音符变为 **红色**，对应按钮红色高亮
- 一组 24 个音符在谱表上同时展示，已答音的对错一目了然

### 📊 练习模式

| 模式 | 说明 |
|------|------|
| 自由练习 | 双谱表随机出题，无限制 |
| 高音谱表专项 | 仅出高音谱表音符 |
| 低音谱表专项 | 仅出低音谱表音符 |
| 双谱表混合 | 随机从两个谱表出题 |
| 错题强化 | 仅从错误率高的音中出题 |
| 限时挑战 | 规定时间内答对尽可能多的题 |

### 🧠 自适应错题强化

- 记录每个音的答题次数、正确次数、错误次数、连续错误次数
- 出题时按错误率加权随机，错误率越高的音出现频率越高
- 连续答对后逐步降低该音的出现权重
- 统计页提供各音掌握情况热力图与正确率趋势

### ⚙️ 个性化设置

- 谱表模式：高音 / 低音 / 双谱表
- 音域范围自定义（C2 ~ C6）
- 是否包含变化音（升号 / 降号）
- 音名提示 / 唱名提示开关
- **默认浅色主题**，可切换深色主题
- 音效开关（正确 / 错误提示音）
- 数据导出 / 导入（JSON），一键重置

### 📱 移动端适配

- 练习界面在手机端一屏内完整显示，无滚动条
- 按钮大尺寸触摸优化，支持触摸反馈
- 禁止页面缩放，防止误触

## 技术栈

| 层级 | 方案 |
|------|------|
| 前端框架 | Vue 3 (Composition API) |
| 状态管理 | Pinia |
| 谱表渲染 | VexFlow 4 |
| 图表 | ECharts |
| 构建工具 | Vite |
| 部署 | GitHub Pages + GitHub Actions |

npm run dev

npm run build

npm run preview

## 项目结构

```
src/
├── components/
│   ├── Staff/            # 谱表组件（VexFlow 封装，支持大谱表）
│   ├── NoteButtons/      # 7 键音名按钮组件
│   ├── Stats/            # 统计图表面板
│   └── Settings/         # 设置面板
├── stores/
│   └── practice.js       # 练习状态管理（24 音组、答题逻辑）
├── services/
│   ├── storage.js        # LocalStorage 存储封装
│   ├── questionGenerator.js  # 自适应出题算法
│   └── audio.js          # Web Audio API 音效
├── utils/
│   └── musicTheory.js    # 乐理工具（音高转换、谱表位置等）
├── App.vue
└── main.js
```
