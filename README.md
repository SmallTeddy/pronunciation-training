# 五线谱识谱训练器

## 项目简介

一个基于 Web 的五线谱识谱练习工具，同时展示高音谱表和低音谱表音符，配合底部音高键盘进行交互练习。无需登录，数据存储在本地，系统会根据用户常错的音自动加强练习。

---

## 核心功能模块

### 1. 谱表展示

- 高音谱表（G 谱号）音符渲染
- 低音谱表（F 谱号）音符渲染
- 支持同时显示双谱表（大谱表模式）或单独切换
- 随机生成音符位置（可配置音域范围）
- 音符符干方向自动判断
- 加线自动绘制
- 可选显示/隐藏音符名称提示

### 2. 音高键盘

- 钢琴键盘布局（建议至少覆盖 C2–C6）
- 点击琴键作答
- 支持键盘快捷键映射（A/K 对应白键，W/E 对应黑键等）
- 作答后视觉反馈（正确绿色 / 错误红色高亮）
- 支持 MIDI 键盘输入（进阶）

### 3. 练习模式

| 模式 | 说明 |
|------|------|
| 自由练习 | 随机出题，无限制 |
| 高音谱表专项 | 仅出高音谱表音符 |
| 低音谱表专项 | 仅出低音谱表音符 |
| 双谱表混合 | 随机从两个谱表出题 |
| 错题强化 | 仅从错误率高的音中出题 |
| 限时挑战 | 规定时间内答对尽可能多的题 |
| 听音辨谱 | 播放音高，用户在谱表上识别（进阶） |

### 4. 自适应错题强化

- 记录每个音的**答题次数、正确次数、错误次数、连续错误次数**
- 计算每个音的**错误率**和**遗忘权重**
- 出题时按权重加权随机选择，错误率越高的音出现频率越高
- 连续答对后逐步降低该音的出现权重
- 可查看各音的掌握情况热力图

### 5. 本地数据存储

- 使用浏览器 **IndexedDB** 或 **LocalStorage** 存储
- 存储内容：
  - 每个音的答题统计数据
  - 练习历史记录（日期、模式、正确率、用时）
  - 用户设置（谱表选择、音域范围、主题等）
- 支持数据导出/导入（JSON 文件），方便备份和迁移
- 支持一键重置数据

### 6. 统计与可视化

- 今日/本周/本月练习概览（答题数、正确率、用时）
- 各音掌握程度热力图（钢琴键盘或谱表上着色）
- 正确率趋势折线图
- 最常错的音 Top N 排行
- 连续练习天数统计

### 7. 设置与个性化

- 谱表显示模式：高音 / 低音 / 双谱表
- 音域范围自定义（如仅中央 C 附近八度，或全音域）
- 是否包含变化音（升号/降号）
- 音符显示时长（自动进入下一题的延迟）
- 是否显示音名提示（C/D/E… 或 Do/Re/Mi）
- 是否显示唱名提示
- 深色/浅色主题切换
- 音效开关（正确/错误提示音）

## 出题算法简述

```
1. 根据当前模式确定候选音集合
2. 从 noteStats 中读取每个音的错误率
3. 按错误率计算权重：weight = base + errorRate * boostFactor
4. 加权随机选择一个音作为题目
5. 用户作答后更新统计数据
6. 若答错，streakWrong++，权重进一步提升
7. 若答对，streakWrong 清零，权重逐步回归基准
```

## 注意事项

- **无需后端**，纯前端静态页面即可运行，部署成本极低
- 首次加载需引入 VexFlow 字体资源，注意 CDN 或本地缓存
- 移动端需适配触摸操作（琴键点击、谱表缩放）
- 乐理逻辑（音高与谱表位置的映射）需仔细校验，建议编写单元测试
